# CLA 4(1): ML Model Deployment Strategies and Model Serving using FastAPI

## Dataset
Titanic - Machine Learning from Disaster (Kaggle): https://www.kaggle.com/competitions/titanic/data  
Use the official `train.csv` file.

## Setup
```bash
py -m venv venv
.\venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```
Place `train.csv` in this folder.

## Run tasks
```bash
py train_model.py
py online_inference.py
py batch_inference.py
py streaming_inference.py
```

## Run the API
Start the server:
```bash
py -m uvicorn app:app --reload
```
Open http://127.0.0.1:8000/docs and test `GET /health` and `POST /predict`.
In a second terminal, run:
```bash
py client.py
```

## Notes
- The script splits the labeled data into training and testing portions.
- The model is trained once and saved as `model.pkl`.
- All inference examples and the API reuse that saved pipeline.
- `unseen_records.csv` contains held-out rows from the test split and is generated by `train_model.py`.
